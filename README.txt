MON BUDGET — version de départ

Projet de mini-application de budget installable (PWA), pensée pour iPhone.
Les données sont enregistrées localement dans le navigateur via localStorage.
Pas de compte, pas de serveur, pas de Supabase.

Pour la mettre en ligne gratuitement :
1. Créer un dépôt GitHub public nommé mon-budget.
2. Décompresser ce ZIP.
3. Ajouter les fichiers du dossier à la racine du dépôt.
4. Dans GitHub : Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Attendre la publication. Ouvrir l'adresse GitHub Pages sur Safari iPhone.
6. Sur iPhone : bouton Partager > Sur l'écran d'accueil.

Important :
- Exporter régulièrement une sauvegarde depuis Réglages.
- Les données sont propres à chaque appareil et navigateur.
- Effacer les données du site peut effacer les données locales.
- Ce projet est une première version fonctionnelle ; amélioration/validation à poursuivre.
